# Entity CLA register

Companies and other legal entities that have signed
[`CLA-CORPORATE.md`](../../blob/main/CLA-CORPORATE.md).

Maintained by hand. Harmony's Entity CLA covers the signing entity and its
affiliates but does not itself name individual employees, so the GitHub
accounts below are an operational convention: they are what lets the CLA bot
recognise which pull requests are already covered.

**When adding an entry, also add the listed accounts to `allowlist` in
`.github/workflows/cla.yml` on `main`.** An entry here alone has no effect on
the automation.

| Entity | CLA version | Signed | Designated GitHub accounts |
|---|---|---|---|
| *none yet* | | | |

## Procedure

1. Entity emails the signed agreement to the maintainer, listing the GitHub
   accounts that will contribute on its behalf.
2. Maintainer files the signed document and adds a row above.
3. Maintainer adds those accounts to `allowlist` on `main`.
4. Later changes to an entity's account list follow the same route — update the
   row and the allowlist together.
